# Brain-Tumor-MRI


## Project Title
Automated Brain Tumor Classification from MRI Images Using Deep Learning

## Problem Statement / Research Question
Can a deep learning model accurately classify brain MRI images into different tumor
categories (Glioma, Meningioma, Pituitary, and No Tumor) to support early and
efficient medical diagnosis?

## Project Description
This project aims to develop a deep learning–based image classification model
that can automatically identify and classify brain tumors from MRI images.
The goal is to explore the potential of convolutional neural networks (CNNs)
as a decision-support tool in medical image analysis.

## Data Source
- Brain Tumor MRI Dataset (Kaggle)  
  https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset

## Tools & Technologies
- Python
- NumPy
- Pandas
- TensorFlow / Keras
- scikit-learn
- Matplotlib / Seaborn
- Jupyter Notebook

## Planned Workflow / Methods
1. Load and explore the dataset
2. Preprocess MRI images (resizing, normalisation)
3. Split data into training, validation, and test sets
4. Build and train a CNN-based model
5. Evaluate performance using accuracy and confusion matrix
6. Visualise and analyse the results

## Expected Outcome / Deliverables
- A trained deep learning model for brain tumor classification
- Model performance evaluation results
- Final presentation summarising objectives, methods, and results
